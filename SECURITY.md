# Security policy

## Supported versions

Security fixes target the latest patch of the latest published 0.x minor.
Earlier 0.x minors are not maintained for security fixes. Upgrade to the latest
published release before checking whether a report still reproduces. Support
for 1.x will be documented when that line is released.

## Report a vulnerability privately

Use GitHub's [Report a vulnerability](https://github.com/whitewolf06/gavia-ui/security/advisories/new)
form when private vulnerability reporting is enabled for the repository. If the
form is unavailable, email the maintainer at
[gorbach.d@outlook.com](mailto:gorbach.d@outlook.com) with a subject beginning
`Gavia UI security`. The presence of this policy does not imply that a GitHub
repository setting has already been enabled.

Include the affected package version, a minimal reproduction, the security
impact and any proposed mitigation. Remove credentials, private application data
and unrelated logs. Do not open a public issue or publish exploit details before
the maintainer has had an opportunity to investigate and coordinate a fix.

The maintainer will review the report, agree on a private way to reproduce the
issue and coordinate disclosure and release notes with the reporter. This project
does not promise a response-time SLA. If you need to follow up, use the same
private channel rather than posting details publicly.

General bugs and feature requests belong in
[GitHub Issues](https://github.com/whitewolf06/gavia-ui/issues).
