Описание

Пересобрать экран выбора цели для первого запуска: сократить количество решений, сделать формулировки понятными без продуктового контекста и сохранить возможность пропустить шаг.

Нужно подготовить состояния для desktop и mobile, проверить длинные переводы и передать разработке готовую спецификацию.

  • Не более пяти целей на первом экране.
  • Выбранная цель должна быть очевидна без дополнительного текста.
  • Продолжение доступно только после выбора.
Цель задачи: увеличить завершение первого шага онбординга с 71% до 82% без ухудшения времени до первого полезного действия.
