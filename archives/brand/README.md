# Archived Gavia UI artwork

These original sources, prompts and historical variants moved from `docs/brand`
on 2026-10-19 as part of review task T8.8. This is a version-controlled archive
inside the owner-controlled repository, outside the active artwork directory.
No external repository, upload or publication is involved. Files were relocated
without conversion; do not optimize, regenerate or discard authored originals.
This separates active assets from sources; it does not reduce Git history size.

The immutable [original inventory](../../docs/brand/archive-proposal.json)
records the original `docs/brand` names, byte sizes and SHA-256 digests below.
The source revision is the dirty review working tree based on `fc7792d`, before
archival; no new commit hash exists. The inventory's historical proposal status
is retained. The [active asset index](../../docs/brand/README.md) and
[maintenance procedure](../../docs/maintainers/brand-archive.md) describe the
current location and recovery. The existing derivative checker reads PNGs here
and still checks their hashes against the recorded provenance; it was not run
after relocation.

## Original social mark

[gavia-social-original.png](gavia-social-original.png) preserves the original 1254 x 1254 public social mark before the new 1280 x 640 composition.
Its SHA-256 is `019f89997145178e97f61bdcea687fc6dd348e4e48cf1212240784f9842f5b52`.

Original artwork provenance is recorded in the adjacent prompts. The social
composition uses the existing final mark and Gavia Regular outlines; font
notices remain in [Gavia OFL](../../packages/ui-kit/fonts/gavia/OFL.txt) and
[Onest OFL](../../packages/ui-kit/fonts/gavia/Onest-OFL.txt). No new AI artwork
was generated or substituted for the authored mark.
