# Дизайн-система 0.6.0: изменения и переход

Версия 0.6.0 объединяет удаление PrimeVue и новую дизайн-систему.
Vue 3 остаётся единственным обязательным peer. Runtime-зависимостей нет.

## Что входит в релиз

- 51 собственный Vue-компонент, 47 SVG-иконок и темы White, Graphite, Newspaper.
- 416 типизированных токенов со слоями foundation → semantic → component,
  единым JSON-источником и проверкой ссылок, контраста и генерации.
- Опциональные классы компоновки и типографики в `styles/primitives.css`;
  каталог `design-tokens.json` и экспорты для получения значений без DOM.
- Копируемые SFC-примеры всех компонентов и шесть рабочих сценариев:
  список материалов, профиль, настройки, карточка материала, мастер проекта
  и загрузка вложений. Примеры проверяются в потребителе упакованного пакета.
- Опциональная анимация оверлеев, поддержка reduced motion, стабильная ширина
  страницы при блокировке прокрутки и исправления фокуса и слоёв оверлеев.
- Контрактные тесты, браузерные сценарии и 78 визуальных эталонов трёх тем
  на desktop/mobile. CI проверяет пакет на Node 18 и 24.

## Переход с опубликованной 0.3

Примените [руководство удаления PrimeVue](migration-0.5.md):
конфигурация переносится в `WlConfig`, используемые сервисы устанавливаются
на Vue-приложении, PrimeVue `<Column>` внутри `WlTable` заменяются
на `columns` и слоты `cell-*`. Эти изменения инициализации относятся и к 0.6.0.

Публичные `Wl*` exports, модели, props, события, слоты, имена SVG-иконок,
`wl-*` классы и прежние CSS-токены сохраняются. Порядок `pt`:
дефолты → конфигурация приложения → экземпляр компонента.

## Переход с рабочей 0.5

Дополнительная обязательная настройка не требуется. Стили по-прежнему
подключаются явно. Для новых классов компоновки добавьте:

```ts
import "gavia-ui/styles/primitives.css";
```

Прежние 165 CSS-токенов сохраняют имена и итоговые значения во всех темах.
Для контраста primary/danger используют новые `--wl-action-primary-*` и
`--wl-action-danger-*` роли. Текст подсказок использует `--wl-text-muted`,
опасных действий — `--wl-text-danger`; клавиатурный фокус явно обведён.
При собственном оформлении задавайте фон, hover и текст действия вместе.

Анимация включена по умолчанию. Для мгновенных переходов используйте
`app.use(WlConfig, { motion: false })` либо локальный `:motion="false"`.
`prefers-reduced-motion` учитывается автоматически.

`WlButton` устанавливает фокус до обработчика клика, чтобы Dialog/Drawer
возвращали его на кнопку открытия в Safari. Ошибки `WlFileUpload` объявляются
через `role="alert"`. Выпадающие панели учитывают слой своего родителя.

## Проверка приложения после обновления

1. Обновите библиотеку до версии с API 0.6. Если переходите на новое имя,
   следуйте [миграции Gavia UI](migration-gavia.md): первый публичный npm-выпуск
   нового имени — [gavia-ui@0.7.0](https://www.npmjs.com/package/gavia-ui).
2. Проверьте сборку, типы и используемые темы, включая собственные токены действий.
3. Проверьте формы, клавиатуру, открытие/закрытие и возврат фокуса оверлеев,
   прокрутку страницы, даты, таблицы и сервисы уведомлений/подтверждений.
4. Сравните плотные и узкие экраны с [правилами дизайн-системы](design-system.md).

В примерах сохранение и ошибки моделируются локально. При переносе подключите
API, валидацию и бизнес-правила приложения. После обновления проверьте
конкретные экраны с их данными и вспомогательными технологиями;
автоматические тесты библиотеки такую проверку не заменяют.
