# Gavia UI: исходники бренда

Актуальный знак — [gavia-ui-mark-v2.png](gavia-ui-mark-v2.png): гагара в форме G,
с круглым прозрачным глазом. Он используется в README и заголовке playground.
Логотип с названием — [gavia-ui-logo-v2-eye.png](gavia-ui-logo-v2-eye.png).

Изображения подготовлены через встроенный imagegen. Прозрачный фон и отверстия
знака сохранены. Точные запросы находятся в `*-prompts.txt` и
`gavia-ui-mark-v2-prompt.txt`; v1 и preview оставлены как история вариантов.

При изменении знака сохраняйте силуэт G, клюв и прозрачный глаз. Проверьте
читаемость в 26 px рядом с названием и версией во всех темах.

## Иллюстрация первого экрана

[gavia-lake-hero-v1.png](gavia-lake-hero-v1.png) — рисованная гагара на тихом
озере с закатным светом, серо-оливковой водой и свободной областью слева под текст.
Изображение создано встроенным imagegen (builtin), без CLI.
Точный запрос: [gavia-lake-hero-v1-prompt.txt](gavia-lake-hero-v1-prompt.txt).

Исходник сохранён в PNG, 1774 × 887. В `HomePage.vue` картинка декоративная
(`alt=""`, `aria-hidden`), абсолютно расположена фоном первого блока на всю
ширину окна и не участвует в раскладке. Внутри остаётся прежний центрированный
контейнер: текст слева, установка справа; на мобильном они складываются в одну
колонку. Размер блоков определяется содержимым, а не картинкой.
Проверяйте клюв, глаз и силуэт птицы при обрезке, читаемость текста и все темы.
Новые варианты сохраняйте рядом с новым суффиксом версии.

Цветовая схема и контраст: [тема Gavia](../theme-gavia.md).
