## Коротко

**Проектом уже можно гордиться.** Инженерная дисциплина заметно выше типичного пет-проекта:
- гейт совместимости по `.d.ts`;
- проверка установленного архива в чистых приложениях на pnpm, npm и Bun с Vue 3.4/3.5;
- axe WCAG 2.2 AA в пяти темах, четыре браузера, визуальная регрессия;
- публикация с provenance;
- ноль runtime-зависимостей и строгие generic-типы.

**До «конфетки» мешают три группы проблем:**
1. **Заметные шероховатости.** Их видит специалист за минуту, а правятся они за неделю:
   - нет линтера и форматтера;
   - в combobox не работает `aria-activedescendant`;
   - `import * as Vue` добавляет пользователям 14.7 КБ;
   - логотип сайта весит 410 КБ;
   - версии в README расходятся.
2. **Вход для человека.** README не продаёт проект, документация перемешана с журналами проверок, CONTRIBUTING на 22 строки, публичная часть на двух языках.
3. **Глубина ключевых компонентов.** У Select нет слотов, у Table — `rowKey`, Toast почти не настраивается. Нет групп чекбоксов и радио, интеграции с роутером, тултипа-компонента. Статусы называются шестью разными способами.
